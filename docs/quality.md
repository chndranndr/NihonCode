## Debts

- `data/generated/index.ts` imports a nonexistent `../../types/content`; excluded from compilation (the gate owns the type contract now). Do not import it; Phase 2 may delete it with the pipeline.
- PRD section 18 counts and audit counts differ by definition in three places (vocab romaji 7,293 vs 7,295; kanji markers 1,130 vs 1,157; remote-image passages 108 vs 103). Definitions documented in [data-quality.md](data-quality.md); the delta is reported to the owner, who owns PRD.md.
- The graded vocab pool is 641, not 643: two latin-romaji entries pack alternatives (Problem C) and are excluded from exact-match grading until they get a variants list.
- `js-yaml` is a devDependency used only by `scripts/doctor.mjs` to validate CI YAML — the one non-stdlib script dependency.

## Review loop

Proportionate loop for non-trivial work (workflows.md): implementation → `npm run check` + `npm test` (+ `npm run eval` for UI) → review (primary agent locally; the impeccable finish reviewer runs inline per its degraded protocol, which mandates inline execution in subagent-less harnesses) → resolve feedback → final verification at the integrated head per DEVELOPMENT_PROMPT.md section 8. Recurring review findings become guardrails via the harden path, not prose.
