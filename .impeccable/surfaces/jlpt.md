# Surface brief: JLPT practice

Mode: Operate. Updated 2026-09-22. Authority and delivery status: [reference map](../README.md). This replaces the historical launch brief for the approved redesign.

Use the JLPT mockup's level/category controls, numbered set list with progress, start action and honest locked categories. Grammar, Kanji and Vocabulary use actual loaded keyed sets for the selected level, not the mockup's three repeated N5 questions.

A run uses accessible radio options, question position, submit/feedback/next, and the shared visual language of practice/results. Preserve existing answer keys, explanations when present, per-set best score, completed state, retry, exit confirmation and browser navigation. Do not invent time limits or exam predictions.

Listening remains gated on audio confirmation; Reading on the owner's passage decision. Never unlock them as part of styling. One completed set contributes to JLPT only, not Drills; aborts do not count. A retry is a distinct run.

Category/set layouts stack on mobile. Missing content has a useful empty/error state rather than falling back to the wrong level. Production redesign integration shipped 2026-09-22; evidence in docs/quality.md "Redesign integration".
